19 MOTORWORKS — LAUNCHING SOON PAGE
=======================================

Files:
- index.html
- styles.css
- script.js
- assets/19-motorworks-banner.jpg

QUICK SETUP
-----------
1. Upload all files/folders to your website hosting.
2. Keep the "assets" folder in the same location as index.html.
3. Open your domain.
4. The page will load as the main homepage.

COUNTDOWN
---------
Open script.js and change:

const launchDate = new Date("2026-10-01T10:00:00+05:30");

Replace the date/time with your actual launch date.

IMPORTANT
---------
If your existing website already has an index.html, do NOT overwrite it unless
you intentionally want this Launching Soon page to replace the whole site.

If you want a temporary Launching Soon page while keeping your current site,
use this page as the homepage and later restore the original homepage.

PLATFORM NOTES
--------------
For cPanel / normal hosting:
Upload index.html, styles.css, script.js and the assets folder into public_html.

For WordPress:
The cleanest method is to use a maintenance/coming-soon plugin or add this
design as a custom page/template. Do not overwrite WordPress core files.

For Shopify:
Use the password/coming-soon page or customize the theme's password template.

For Wix/Squarespace:
Use their built-in coming-soon/maintenance page and reproduce the design,
because these platforms generally do not work like normal file hosting.
